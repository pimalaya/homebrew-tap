# Pimalaya Homebrew tap

Homebrew formulae for the Pimalaya CLIs, on macOS and Linux:

```sh
brew install pimalaya/tap/ortie
```

Each formula installs the prebuilt binary of the latest GitHub release, with its man pages and shell completions. The formulae are written, tested and pushed by [pimalaya/packages](https://github.com/pimalaya/packages): do not edit them by hand.
